# C2 报告：多跳失败概率预算

> 创新点 C2 —— 面向多跳可用性的 NTRU 代理重加密
> 代码：`pyref/hop_sim.py`（数值核心）、`pyref/mc_failprob.py`（预算层）
> 数据：`bench/results/c2_mc_curve.csv`、`c2_budget.csv`、`c2_threshold.csv`

---

## 1. 问题与目标

代理重加密（PRE）的多跳能力在原始方案里只有**经验值**：论文对每个参数集给一个"能撑几跳"，
但没有回答**这个跳数对应多大的解密失败概率**，也无法回答**给定失败概率预算，最多能跳几次**。

C2 要把"经验跳数"升级为**预算**：

> 给定目标失败概率 δ（低到 `2^-40`），反解可支持的跳数 `h_max(δ, 参数集, 门限配置)`。

并且量化**门限化（C1）的代价**：把委托凭证从单代理改成 `t`-of-`N` 门限，噪声会被放大，
可用跳数会下降多少。

---

## 2. 方法

### 2.1 噪声核

`h` 跳链 `A → B₁ → … → B_h`，接收方用 `f_{B_h}` 解密：

```
f_{B_h}·C_{B_h} = f_A·C_A + p·Σ_{i=1..h} e_i·f_{B_i}
                = p·( g·s + F_A·M + Σ_{i=1..h} e_i·f_{B_i} ) + M
```

定义**噪声核**

```
T_h = g·s + F_A·M + Σ_{i=1..h} e_i·f_{B_i}          (f = 1 + p·F)
```

解密正确 ⟺ `center(p·T_h + M) mod q` 再 `mod p` 等于 `M`（与 C++ 引擎判据逐位一致）。

三条决定方法可行性的性质：

1. **零漂移**：`Σ(g) = Σ(F_A) = Σ(e) = 0`，`Σ(f_B) = 1` ⇒ `Σ(T_h)` 是常数，
   故系数零均值、**方差随 h 线性增长** —— 这正是大偏差分析的标准结构。
2. **只在小整数域做卷积**：操作数是 `e ∈ {−1,0,1}` 与 `f_B`（系数 ∈ `{−3,0,3}`，常数项 ∈ `{−2,1,4}`），
   **从不出现满量程的 `C_A·rk`**。因此浮点 FFT 批量卷积的舍入误差约 `1e-7`，远小于取整门限 0.5，
   取整无损（仍以 `fft == exact` 的逐位对拍兜底）。
3. **h 可解析放大**：`T_h = C₀ + Σ_{i≤h} W_i`（`C₀` 与单跳增量 `W` 独立），故

   ```
   K_{T_h}(t) = K_{C₀}(t) + h·K_W(t)
   ```

   鞍点方程可以按 `h` 直接放大，不必为每个跳数重新做经验估计。

### 2.2 蒙特卡洛

按上述结构直接模拟：每批采样 `g, s, F_A, M` 得公共部分 `C₀`，逐跳累加 `W_i = e_i·f_{B_i}`，
在**同一条链**上检查 `h = 1, 2, …` 是否失败（共用随机数，跨 h 的估计因此相关 —— 这是有意的方差缩减，
每个 h 的 δ 仍无偏）。

- 后端：`fft`（CPU/NumPy，默认）／`cupy`（GPU，需在 WSL 中使用）／`exact`（int64 参照，用于验证）。
  `n ∈ {439,1087,1171,1499}` 均为素数，直接做循环 FFT 会退化为 Bluestein，
  故**补零到 2 的幂做线性卷积再折回**，实测快 1.4~1.9 倍且逐位精确。
- 每个批次用 `(seed, 批次号)` **独立播种**，使结果不随模拟的跳数范围变化，保证可复现。
- 一律报 Wilson 95% 置信区间，不报裸点估计。

### 2.3 鞍点尾部模型

纯 MC 测不到 `2^-40`。用**鞍点（Lugannani–Rice）**外推：由样本估经验 CGF `K(t) = log E[e^{tW}]`，
解鞍点方程 `K'(ŝ) = τ`（阈值 `τ = (q/2)/p ≈ 341`），再取双侧（`T_h` 的系数分布对称）：

```
p₁(h) = P(|T_h 单个系数| > τ) ≈ 2·[ 1 − Φ(w) + φ(w)(1/v − 1/u) ]
  w = sqrt(2(ŝτ − K(ŝ))),  v = ŝ·sqrt(K''(ŝ)),  u = (1 − e^−ŝ)·sqrt(K''(ŝ))
δ(h) ≈ 1 − (1 − p₁)^n                       # 对 n 个系数的并集界
```

工程要点：

- `1 − Φ(w)` 用 `0.5·erfc(w/√2)` 计算，避免大 `w` 时的灾难性抵消；全程在 log 空间，以免 `2^-40` 量级下溢。
- 经验 CGF 只在"倾斜后有效样本量 ESS ≥ 500"的范围内可信；超出该范围用**在 `t_max` 处二阶匹配的二次延拓**
  （锚在实测 CGF 上，比从均值做高斯近似准得多；真实 `W` 有界，二次延拓使尾部偏重 ⇒ δ 偏保守）。
- **标定**：在 MC 可测区间按事件数加权拟合一个乘性常数（权重取 `failures/(1−δ)`）。
  另单独输出 `log10(δ_MC / δ_模型)` 的**极差（漂移）** —— 那才是外推不确定度的主项。

**收敛性**：固定 MC 曲线、只改 CGF 样本数（EES439）：

| CGF 样本数 | `t_max` | δ(1) | δ(2) | δ(3) | `h_max(2^-40)` |
|---|---|---|---|---|---|
| 5 万 | 0.0546 | 6.2e-11 | 2.0e-05 | 2.5e-03 | 0 |
| **20 万**（采用） | 0.0661 | 1.0e-11 | 1.0e-05 | 1.9e-03 | 0 |
| 80 万 | 0.0788 | 2.5e-12 | 9.2e-06 | 2.0e-03 | 0 |

δ(2)、δ(3) 与 `h_max(2^-40)` 在 20 万以上已稳定；
但 **δ(1) 仍在缓慢下降**（6.2e-11 → 1.0e-11 → 2.5e-12），说明**越往深处、数值越只有量级意义**。
采用 `--cgf-samples 200000`，并把"1 跳的失败率"读作"低于某量级"而非精确值（见 §5）。

### 2.4 门限（C1）耦合

门限组合把全部 `m = C(N, t−1)` 份部分重加密直接相加，每份各带一个 `p·e_S`，且**共用同一个** `f_B`：

```
Σ_S ( C_A·share_S + p·e_S ) = C_A·rk + p·Σ_{k=1..m} e_k
```

⇒ **门限版完全等价于基线把单跳噪声 `e_i` 换成 `Σ_{k=1..m} e_k`**。

由此每跳仍只做**一次**卷积，代价仅为 O(m) 次采样 —— 否则 `m = 56` 的配置要付 56 倍卷积开销。
这使门限代价曲线可以便宜地扫完 `m = 1 … 56`。

## 3. 正确性验证

| # | 断言 | 结果 |
|---|---|---|
| 1 | 采样器：恰好 `d` 个 +1 / `d` 个 −1；`P(+1) ≈ P(−1)`；`P(≠0) = 2d/n` | ✅ |
| 2 | **`T₁ == g·s + F_A·M + e·f_B`，与 C++ 引擎导出的测试向量逐位对拍** | ✅ max\|diff\| = **0** |
| 3 | `fft == exact` 逐位一致（6 个参数集：4 个 EES/APR + 2 个教学参数） | ✅ |
| 4 | 失败判据 == C++ 的 `poly_mod_p_centered` 直译版；且与 ∞-范数代理判据事件数一致 | ✅ |
| 5 | `Var(g·s 的系数) == 4·dg·dr/n`（抽样层面的理论值）；偏度 ≈ 0 | ✅ |
| 6 | 单跳增量 `W` 的系数分布对称、零均值（§2.3 中 `p₁ = 2·P(T_h > τ)` 的前提） | ✅ |
| 7 | **结果不随模拟的跳数范围变化**（同 seed 下 `max_hops` 取 22/30/42 给出完全相同的计数） | ✅ |

**断言 2 是最有价值的一条**：它取 C++ 引擎真实算出的密文与中间量，用 Python 独立重算噪声核并逐位比对。
模型公式不是"推导完就算数"，而是被实数验过的。事实上正是它抓出了实现里的一处不一致
（明文表示约定，见 §5）。

**参数来源核对**：对应参数集的 `df / dg / dr / dm0` 已逐项与原始实现核对。
`dg` 与 `dr` 在该实现中并非独立参数（由 `dr = df`、`dg = n/3` 推导）。
核对过程中发现并修正了一处参数误读，修正后 `δ ≈ 10%` 对应的跳数由 6 变为 5，与论文一致（§4.2）。

## 4. 结果

**口径**：每条曲线 30000 条链，CGF 样本 20 万，`seed = 1`，后端 `fft`（CPU / NumPy）。
所有数字均取自 `bench/results/c2_*.csv`。

### 4.1 失败概率曲线 δ(h)

以 `m = 1`（无门限）为例（`δ` 为 MC 实测，`δ_模型` 为鞍点模型）：

| 参数集 | δ(h) 的上升区间 | 标定常数 | 最大残差 | 漂移 |
|---|---|---|---|---|
| EES439 | h=4 (3.1%) → h=6 (37.5%) | 1.002 | 0.091 dec | 0.092 dec |
| EES1087 | h=14 (4.4%) → h=19 (36.1%) | 1.002 | 0.038 dec | 0.039 dec |
| EES1171 | h=19 (3.9%) → h=26 (35.6%) | 1.002 | 0.075 dec | 0.095 dec |
| EES1499 | h=42 (3.1%) → h=59 (38.0%) | 1.015 | 0.042 dec | 0.055 dec |

**标定常数全部落在 1.0015~1.0152** —— 也就是说模型几乎不需要事后修正，形状本身就是对的。
残差与漂移已在 CSV 中逐条给出，未做拟合抹平。

### 4.2 与论文 Table 4 对拍

论文的 `# Hops` 定义是"**平均可支撑的重加密次数**"（一个停时统计量），
并非"某个固定失败率对应的跳数"。论文表中每个参数集有两行（是否使用 product-form 密钥），
下表对照的是**非 product-form** 那四行 —— 与本模拟器的口径一致。

| 参数集 | 论文 `#Hops` | 该跳的 δ（本文实测） | 我们 `h@δ=0.1` | |
|---|---|---|---|---|
| EES439 | 5 | 14.42% | **5** | ✅ 一致 |
| EES1171 | 21 | 9.08% | **22** | ✅ 差 1 跳 |
| EES1499 | 50 | 13.08% | **49** | ✅ 差 1 跳 |
| EES1087 | 21 | 56.66% | **16** | ❌ 差 5 跳，未解释 |

**结论**：按"同一失败量级下的跳数"比较，四个参数集中**三个落在 ±1 跳内**。

**关于 EES1087，如实说明 —— 并且这里有一个容易被忽略的口径问题**：

论文对 `# Hops` 的原文定义是"**平均可支撑的重加密次数**"，即停时统计量 `E[H]`。
若按论文自己的这个定义去算，结果**恰好相反**：

| 口径 | EES439 | EES1087 | EES1171 | EES1499 |
|---|---|---|---|---|
| `h @ δ=0.1` | 5 ✅ | 16 ❌（论文 21） | 22 ✅ | 49 ✅ |
| **`E[H]`（论文定义）** | 7.0 ❌（论文 5） | **20.9 ✅**（论文 21） | 28.4 ❌（论文 21） | 62.6 ❌（论文 50） |

也就是说：**按论文自己给的定义，对不上的是另外三个**，而且我们的 `E[H]` **系统性偏高 30~40%**，
EES1087 反而是唯一吻合的。这比"单个参数集离群"更值得注意 —— 它提示
我们重建的 `E[H]` 与论文的实验流程（100 次迭代、每次迭代换新密钥、失败如何判定）并不完全等价。

已排除的原因：参数值（逐项与原始实现核对）、噪声分布（平衡三元、重量 `dr`）、
`f = 1 + p·F` 约定、解密判据 —— 均已核对一致。剩余差异需要复现其原始实验流程才能定性。

**因此本项目不声称"完全复现论文 Table 4"。** 稳妥的表述是：
在同一失败量级（δ≈10%）下，四个参数集中三个与论文相差 ≤1 跳；
而按论文原文的停时定义比较时，结论会反过来 —— **两种口径尚未统一，宜并列给出而不是择一断言**。

### 4.3 跳数预算 h_max(δ)

| 参数集 | δ = 1e-3 | δ = 1e-6 | δ = 2^-40 |
|---|---|---|---|
| EES439 | 2 | 1 | 0 |
| EES1087 | 9 | 5 | 3 |
| EES1171 | 13 | 8 | 4 |
| EES1499 | 30 | 19 | 10 |

**读法**：论文给出的经验跳数大致落在 δ ≈ 10% 一档；要压到 `2^-40`，可用跳数大约要**砍掉三分之二**。
`0` 表示连 1 跳都超预算 —— 注意这是**参数集自身 1 跳的噪声底**就已接近该量级所致，是方案的固有属性。

### 4.4 门限化的代价

`m = C(N, t−1)` 是门限化后每跳多出的噪声份数。目标 δ = 1e-3 时的可用跳数：

| 参数集 | m=1 | m=3 | m=5 | m=10 | m=15 | m=35 | m=56 |
|---|---|---|---|---|---|---|---|
| EES439 | 2 | 0 | 0 | 0 | 0 | 0 | 0 |
| EES1087 | 9 | 3 | 1 | 0 | 0 | 0 | 0 |
| EES1171 | 13 | 4 | 2 | 1 | 0 | 0 | 0 |
| EES1499 | 30 | 10 | 6 | 2 | 2 | 0 | 0 |

（代理配置与 m 的对应：`(3,2)→3`、`(5,2)→5`、`(5,3)→10`、`(6,3)→15`、`(7,4)→35`、`(8,4)→56`。）

**为什么大 `m` 会归零**：看"1 跳的失败率"最直观 ——

| 参数集 | m=1 | m=3 | m=5 | m=10 | m=15 | m=35 | m=56 |
|---|---|---|---|---|---|---|---|
| EES439 | ≈0 | 2.5e-3 | 1.5e-1 | 9.9e-1 | 1 | 1 | 1 |
| EES1087 | ≈0 | ≈0 | ≈0 | 1.6e-3 | 7.9e-2 | 1 | 1 |
| EES1171 | ≈0 | ≈0 | ≈0 | 3.3e-5 | 3.9e-3 | 9.0e-1 | 1 |
| EES1499 | ≈0 | ≈0 | ≈0 | ≈0 | ≈0 | 5.3e-3 | 2.8e-1 |

⚠️ **这一条要单独强调**：早先按 ∞-范数测得的"门限噪声放大仅 1.2~2.7 倍"听起来温和，
**但那是噪声的放大倍数，不是失败概率的**。δ 对噪声是**指数敏感**的 —— 折成可用跳数就是腰斩再腰斩。
报告中若只给"噪声放大 2.3 倍"会严重低估 C1 的代价，必须与上表一并给出。

**读法**：把腐化阈值从 1 个代理提到 `t` 个，代价是可支持跳数大幅下降，且在严预算下直接归零：

- **EES439 最脆**：δ = 1e-3 的预算下，`m ≥ 3` 就无法门限化；
- EES1087 / EES1171：`m ≈ 10~15` 为止；
- **EES1499 最鲁棒**：`m = 35` 仍可用。

## 5. 局限与不确定度

1. **深尾外推只有量级意义**。`δ(1)` 从 `1e-11`（EES439）到 `1e-81`（EES1499），
   这些数字完全依赖经验 CGF 的二次延拓。收敛性实测（§2.3）显示 δ(2)/δ(3) 与 `h_max` 稳定，
   但 **δ(1) 本身仍在下降**（20 万 → 80 万又变了 4 倍）。因此这些值**只能按量级读**。
   实用结论是稳的：除 EES439 外，其余三者的 `δ(1)` 都远低于 `2^-40`；
   EES439 的 `δ(1)` 约 `1e-11`，其 `h_max(2^-40) = 0`（连 1 跳都超预算）—— 这个定性结论不受影响。
2. **并集界 `δ ≈ n·p₁` 在 h 较小时偏高**（漂移 0.046~0.160 decade，已量化输出）。成因是
   小 h 时各系数失败相关性强、并集界高估较多；h 增大后趋于独立、界收紧。该偏差未做拟合抹平。
3. **MC 可测下限**：本报告数据在 3 万样本下，δ 实测下限约 `3e-5`。`1e-6` 以下完全依赖模型外推。
   进一步降低需 GPU 后端（`--backend cupy`）与 `~1e7` 样本量。
4. **明文表示约定**：方案对明文 `M ∈ R/p` 的整数提升有两种常见取法（模 p 的 `{0,1,2}` 与中心 `{−1,0,1}`），
   两者在环中等价、都能正确解密，但**噪声余量相差约 6%**。本模拟器采用与 C++ 引擎一致的取法，
   而论文的参考实现采用中心取法；在关心的跳数区间两者对 δ 的影响约 1~2%，不影响结论，但口径需说明。
5. **两个教学参数集**（`n = 7` / `n = 61`）安全性为零、噪声远小于 `q/2`，永不失败，
   只能用于算术精确性验证，不可用于失败概率统计。
6. **随机源**：本模拟器使用确定性伪随机数，仅用于概率建模，不用于生成真实密钥。
   正式密钥生成须使用密码学安全随机源。

---

## 6. 小结

- 把"经验跳数"升级成了**可查询的预算**：`h_max(δ, 参数集, 门限配置)`。
- 尾部外推用**鞍点（Lugannani–Rice）+ MC 标定**，标定常数收敛到 **1.002~1.016**，
  即模型几乎无需事后修正。
- 建立了**门限化的代价曲线**：`m = C(N,t−1)` 与可用跳数的关系，并指出
  "噪声放大 1.2~2.7 倍"在失败概率维度上被指数放大，可用跳数会腰斩。
- 全部结论都有可复现的产物：`bench/results/c2_*.csv` + 7 类硬断言自检（含与 C++ 引擎的逐位对拍）。
- 与论文 Table 4 对比：**4 个参数集中 3 个在 ±1 跳内一致**；EES1087 存在未解释差异，已如实标注。
